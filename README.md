# Travel Advisor
![Travel Advisor](https://i.ibb.co/qph2cZn/image.pngg)

A modern and user-friendly travel advisor website designed to help users explore destinations, discover interesting places, and plan their next adventure. The project focuses on creating a smooth browsing experience with an intuitive interface and useful travel information.
✨ Features
Explore Destinations – Discover popular travel destinations and nearby attractions.
Search & Discover – Find places based on your travel interests.
Travel Information – View details about destinations, including useful information for planning a trip.
Responsive Design – Enjoy a consistent experience across desktop, tablet, and mobile devices.
Interactive Interface – Navigate through destinations with an engaging and easy-to-use UI.

🛠️ Tech Stack
Frontend: HTML, CSS, JavaScript, React JS
API Integration: Google Maps API
Version Control: Git & GitHub
